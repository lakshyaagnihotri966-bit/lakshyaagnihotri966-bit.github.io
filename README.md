# Portfolio (GitHub Pages + Supabase)

## 1. Supabase (once)
1. Supabase > **Authentication > Users > Add user**: email `lakshyaagnihotri966@gmail.com`, set a NEW strong password, tick **Auto Confirm User**.
2. **SQL Editor** > paste all of `supabase.sql` > Run.
3. (Recommended) Authentication > Sign In / Providers: turn OFF "Allow new users to sign up".

## 2. GitHub
1. Create a repo named exactly `lakshyaagnihotri966-bit.github.io` (public).
2. Upload ALL files of this folder to the repo root.
3. Settings > Pages > Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Site: https://lakshyaagnihotri966-bit.github.io

## 3. Use it
Open `/admin.html`, log in, edit everything, press **Save**. Certificates: Certificates tab > Add > upload image/PDF > Save.

## 4. SEO
Search Console (search.google.com/search-console) > add the URL > submit `sitemap.xml`. Titles, description, share preview and JSON-LD are already in `index.html`.
